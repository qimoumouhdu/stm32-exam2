第二期考核 —— STM32 I2C 外设驱动与 MPU6050 姿态数据采集

功能

MPU6050 寄存器级驱动（不依赖第三方库，纯 HAL）
陀螺仪静态零偏校准（1000 次采样求平均）
一阶低通滤波（α = 0.2）
互补滤波姿态解算（α = 0.98）：roll / pitch / yaw
数据就绪中断驱动采样（PB5 / EXTI5，100Hz）
VOFA+ FireWater 协议实时曲线

|器件              | 连接                                  |
|                  |                                      |
| STM32F103C8T6    | 72MHz（HSE 8MHz × 9）                 |
| MPU6050 (GY-521) | I2C1，PB6=SCL / PB7=SDA，100kHz       |
| MPU6050 INT      | PB5（EXTI5，上升沿）                  |
| USB-TTL          | USART1，PA9=TX / PA10=RX，115200 8N1 |

## 关键参数

| 项目     | 配置                   |
|          |                       |
| 采样率   | 100Hz（SMPLRT_DIV = 9）|
| 数字低通 | 44Hz（CONFIG = 0x03）  |
| 陀螺量程 | ±250°/s（系数 131）     |
| 加计量程 | ±2g（系数 16384）       |

## 已知现象

yaw 会以约 0.04°/s 缓慢漂移 —— 这是正常的，因为加速度计无法感知绕竖直轴的旋转，yaw 只能靠陀螺积分，误差累积导致漂移。修正需要引入磁力计。
